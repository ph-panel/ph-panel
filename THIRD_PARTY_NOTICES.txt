# Third-party software installed by PH-PANEL

PH-PANEL installs the programs below as separate software, unmodified from their upstream releases, each with its own licence file kept next to it.
None of them is part of the PH-PANEL programs themselves.

| Program | Version | Licence | Where it is installed |
| --- | --- | --- | --- |
| Roundcube Webmail | newest release at install time | GPL-3.0-or-later | /opt/phpanel/webmail/roundcube (licence file: COPYING) |
| RCMCardDAV (Roundcube address book plug-in) | 5.1.5, sha256 aea05586822848d9b2f2cdac6b59bdd500d3f93b1b0eeba0295a4aaeb335ad18, source https://github.com/mstilkerich/rcmcarddav | GPL-2.0-or-later | /opt/phpanel/webmail/roundcube/plugins/carddav (licence file: LICENSE) |
| SnappyMail | newest release at install time | AGPL-3.0 | /opt/phpanel/webmail/snappymail (licence file: LICENSE) |
| phpMyAdmin | newest release at install time | GPL-2.0-or-later | /opt/phpanel/dbadmin/phpmyadmin (licence file: LICENSE) |
| SabreDAV 4.7.1 with sabre/event, xml, http, uri, vobject and psr/log | vendored in steps/dav/vendor | BSD-3-Clause, MIT | /opt/phpanel/dav/vendor (licence files kept) |
| ClamAV (scanner program clamscan only; optional malware scan) | the version of the system packages | GPL-2.0 | installed by the system package manager when an administrator switches the malware scan on (licence files under /usr/share/doc/clamav*) |
| Linux Malware Detect signatures (rfxn.hdb, rfxn.ndb; optional malware scan) | newest at install time, renewed weekly, from https://cdn.rfxn.com/downloads/maldet-sigpack.tgz (project: https://github.com/rfxn/linux-malware-detect) | GPL-2.0 | /var/lib/phpanel/malware/sigs (only the two signature files are used; the Linux Malware Detect program is not installed) |

RCMCardDAV is downloaded from the upstream release page, checked against the checksum above and stored as it was published. Its source code is the
archive itself (PHP). The malware scan is off until an administrator switches it on; ClamAV runs only as the program clamscan (no daemon) and its
signature files are only read by it. Questions about any licence: office@ph-panel.com.
